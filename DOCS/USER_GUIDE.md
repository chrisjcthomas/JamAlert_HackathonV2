## Getting Started

JamAlert is Jamaica's community resilience alert system designed to keep you informed about emergencies, weather conditions, and community incidents in your area.

### What You Can Do
- **Receive Emergency Alerts**: Get notified about floods, hurricanes, earthquakes, and other emergencies
- **Report Incidents**: Share information about incidents in your community
- **Stay Informed**: Access real-time weather updates and community information
- **Customize Preferences**: Choose how and when you receive notifications

### System Requirements
- **Web Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Mobile**: iOS 12+ or Android 8+
- **Internet Connection**: Required for real-time updates

## Account Registration

### Creating Your Account

1. **Visit the Registration Page**
   - Go to [jamalert.jm/register](https://jamalert.jm/register)
   - Click "Create Account" from the homepage

2. **Fill in Your Information**
   - **Personal Details**: First name, last name, email address
   - **Contact Information**: Phone number (for SMS alerts)
   - **Location**: Select your parish and provide your address
   - **Password**: Create a strong password (minimum 8 characters, include letters, numbers, and symbols)

3. **Choose Your Alert Preferences**
   - **Email Alerts**: Receive alerts via email
   - **SMS Alerts**: Receive alerts via text message
   - **Emergency Only**: Only receive critical emergency alerts
   - **Push Notifications**: Get browser/app notifications

4. **Verify Your Account**
   - Check your email for a verification link
   - Click the link to activate your account
   - You can now log in and start receiving alerts

### Account Security Tips
- Use a unique, strong password
- Enable two-factor authentication if available
- Keep your contact information updated
- Log out from shared computers

## Reporting Incidents

### When to Report

Report incidents that could affect community safety:
- Flooding or water damage
- Road hazards or closures
- Power outages
- Infrastructure damage
- Safety concerns
- Environmental hazards

### How to Report an Incident

1. **Access the Report Form**
   - Go to "Report Incident" from the main menu
   - Or visit [jamalert.jm/incidents/report](https://jamalert.jm/incidents/report)

2. **Provide Incident Details**
   - **Type**: Select the incident category
   - **Location**: Provide specific location information
   - **Description**: Describe what happened
   - **Severity**: Rate the severity level
   - **Photos**: Upload relevant images (optional)

3. **Contact Information**
   - Provide your contact details
   - Choose to report anonymously if preferred
   - Include phone number for follow-up

4. **Submit Your Report**
   - Review all information
   - Submit the report
   - You'll receive a confirmation with a reference number

### Report Status Tracking

- **Pending**: Report received and under review
- **Investigating**: Authorities are investigating
- **Verified**: Report confirmed and verified
- **Resolved**: Issue has been addressed
- **False Report**: Report determined to be inaccurate

## Accessibility Features

JamAlert is designed to be accessible to all users, including those with disabilities.

### Visual Accessibility

**High Contrast Mode**
- Increases contrast for better visibility
- Available in Settings > Accessibility
- Helps users with visual impairments

**Large Text Mode**
- Increases text size throughout the application
- Multiple size options available
- Maintains layout and functionality

**Font Size Options**
- Small, Medium, Large, Extra Large
- Applies to all text content
- Saves your preference

### Motor Accessibility

**Keyboard Navigation**
- Full keyboard support
- Tab through all interactive elements
- Keyboard shortcuts for common actions
- Skip links for quick navigation

**Large Click Targets**
- Buttons and links are easy to click
- Minimum 44px touch targets
- Suitable for users with motor difficulties

### Cognitive Accessibility

**Reduced Motion**
- Minimizes animations and transitions
- Helps users with vestibular disorders
- Available in accessibility settings

**Clear Navigation**
- Consistent layout and navigation
- Clear headings and structure
- Breadcrumb navigation

### Screen Reader Support

**ARIA Labels**
- All interactive elements are properly labeled
- Screen readers can navigate effectively
- Alternative text for images

**Semantic HTML**
- Proper heading structure
- Landmark regions
- Form labels and descriptions

## Troubleshooting

### Common Issues

**Not Receiving Alerts**
1. Check your notification preferences
2. Verify your contact information is correct
3. Check spam/junk folders for emails
4. Ensure your phone can receive SMS messages
5. Contact support if issues persist

**Login Problems**
1. Verify your email and password
2. Try resetting your password
3. Clear browser cache and cookies
4. Try a different browser
5. Contact support for account issues

**Website Loading Issues**
1. Check your internet connection
2. Try refreshing the page
3. Clear browser cache
4. Try a different browser
5. Check if the site is under maintenance

**Mobile App Issues**
1. Update to the latest app version
2. Restart the app
3. Check notification permissions
4. Restart your device
5. Reinstall the app if necessary

### Performance Issues

**Slow Loading**
- Check internet connection speed
- Close unnecessary browser tabs
- Clear browser cache
- Try during off-peak hours

**Missing Features**
- Ensure JavaScript is enabled
- Update your browser
- Check browser compatibility
- Disable ad blockers temporarily

### Accessibility Issues

**Screen Reader Problems**
- Update your screen reader software
- Try different browsers
- Enable screen reader mode in settings
- Contact support for specific issues

**Keyboard Navigation Issues**
- Enable keyboard navigation in settings
- Try different browsers
- Check for browser extensions conflicts
- Report specific navigation problems
